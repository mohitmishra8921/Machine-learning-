## 📖 About This Repository

This repo documents my journey learning **Machine Learning fundamentals with scikit-learn** — starting from core building blocks like model training, evaluation, and visualization, and expanding as I cover more algorithms and techniques.

Every notebook here is hands-on: real code, real datasets, real output — not just theory.

---

## 🗂️ Repository Structure

| Folder | Focus Area |
|:---|:---|
| `sk-learn basics/` | Core scikit-learn workflow — training models, plotting decision trees with `plot_tree`, and visualizing results with Matplotlib |

> This repo is actively growing — new folders will be added as I work through more ML algorithms (regression, classification, clustering, model evaluation, etc.)

## 🚀 How to Run

1. Clone the repo:
```bash
   git clone https://github.com/mohitmishra8921/Machine-learning-.git
```
2. Install the required libraries:
```bash
   pip install scikit-learn matplotlib pandas numpy jupyter
```
3. Open any notebook inside `sk-learn basics/` with Jupyter:
```bash
   jupyter notebook
```
